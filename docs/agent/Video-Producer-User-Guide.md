# Video Producer — User Guide v4.6

Updated November 25, 2026. Replaces User Guide v4.5.

## What the agent uses

Video Producer uses an installed production Skill for its procedures, tools, templates and brand assets, and product Collections for evidence and source references: **LakeSentry, Antares, SecondStack and Alchemist**. You can add your own sources: a repository link, files or notes.

All videos and newly authored deliverables are in **English**, with language recorded as `en`. Every video follows the product brand book.

## Current production scope

Every video is built as a sequence of branded scenes in the product's brand book style, like the LakeSentry videos: title, key number, steps, product screen (a screenshot or a screen recording) and call to action. Logo, colours, fonts and the on-screen disclosure come from the brand book. Three formats are available: Shorts 9:16 (laid out inside the Shorts safe zone), YouTube 16:9 and LinkedIn 1:1.

If you ask for something the toolkit cannot yet produce on brand, the agent tells you once what is missing and what it can do instead. It does not silently replace your request.

## 1. Start a video

Open a direct chat with **Video Producer**, or mention it with `@` where it is available. Use one conversation per video.

The agent asks questions in two short steps. Answer what you know; the rest uses defaults. "Defaults for everything" is a valid answer.

Messages stay short and non-technical. The agent keeps file names, versions and checks in its own records and tells you only what you need to decide or do.

**Before the script**
1. Product and topic — or ask it to propose topics
2. Format and duration — Shorts 9:16 / YouTube 16:9 / LinkedIn 1:1
3. Voice — none / I have a recording / give me the text and I will voice it
4. Your input — key messages, points to include or avoid, audience, examples, and extra sources (repository link, files, notes)

**Brief and outline**
Before the script, the agent shows a short brief with the key message, an outline of 3–7 beats and the main claims with their sources, and waits. Add your own points, examples or sources, or say "go ahead".

**After you approve the script**
1. Captions — burned in / separate SRT / both / none (only for videos with a voice). Burned-in captions need a caption-rendering route that is not yet installed; until then the agent delivers a checked SRT file to upload with the video.
2. Background audio — none / generated by the agent / my own

## 2. Review the script

The agent always prepares a text script first: on-screen text, visuals, timing, narration and CTA per scene. For each scene that shows the product, the script also says how the interface will be shown: a screen recording, screenshots, your own recording or screenshots, or a redrawn interface labelled as an illustration.

Reply in plain language:

> Shorten scene 2 and drop the claim about savings.

When you are happy, answer the agent's question "Any more changes, or shall we render?" with "render", "yes" or similar. That approves the exact version shown; the agent records the version and hash. A changed script needs a new approval.

For videos of **3 minutes or longer**, an **animatic** follows the script once the toolkit supports it: a low-resolution draft with placeholders, final on-screen text, timing and draft audio, so you can check the story visually before production.

## 3. Voice

- **You already have a recording:** attach it (MP3, WAV, M4A or MP4; the agent converts it to MP3). The agent transcribes it, shows you the text and builds the scenes around your recording.
- **You need the text:** after script approval the agent sends `VOICEOVER.txt`, ready to paste into ElevenLabs Text to Speech or to read aloud. Export MP3 and send it back in the chat.
- After receiving audio, the agent checks it against the script, trims silence, levels the volume and fits the video to the voice. It asks before cutting phrases or speeding up the recording.

## 4. Background music and sound effects

After you approve the script, the agent asks whether you want background audio. By default there is none. If you want it, the agent generates music and effects for the video; listen to them in the preview. You can always supply your own audio if you have the right to use it.

## 5. Your own sources

Send a repository link and the agent reads what it needs (read-only). For a private repository, attach it as a ZIP archive (GitHub: Code → Download ZIP). Alternatively the agent opens GitHub in its browser and hands it to you to sign in; it then downloads the archive once, signs out and deletes the session. Note that this session gives the agent full access to your GitHub account while it is open. Personal connections under Settings → Connections are not available to the agent.

## 6. Product screens

The script names how each product scene is shown. After approval the agent records or screenshots the product itself in its browser. If a login is required, it hands you the browser in the chat: log in and give control back.

It asks you for a recording or screenshots only when something specific blocks it, for example a VPN-only environment. A redrawn interface is built only from a real screenshot and is labelled as an illustration. Use demo accounts and demo data only.

Every scene is labelled honestly on screen: a real recording or screenshot shows its capture date and "demo data"; an illustration says it is not product UI.

## 7. Preview, final and YouTube copy

- Rendering takes time: roughly 10 seconds per second of video for the preview and about twice as long for the final. For videos longer than a minute the agent tells you the estimate first.
- Preview: a playable MP4 at 30 fps for the full duration. Watch and listen to all of it, ideally on a phone, and give specific feedback with timecodes.
- Final: after you accept the preview, the agent prepares the final MP4 at 60 fps without changing content. Accept the final separately.
- Cover: with the preview you get a branded cover image from the title scene (1280×720 for YouTube, 1080×1920 for Shorts, 1080×1080 for LinkedIn). Ask for a different moment if you prefer.
- After final acceptance the agent asks whether you want a YouTube title and description. If you do, it sends title options and a ready-to-paste description as text. You upload and publish the video yourself; the agent does not upload or publish anything.

## 8. Continuing later

Ask for a short English handoff note (stage, open issues, next action) when you pause. Keep the script and media attachments in the same conversation.
