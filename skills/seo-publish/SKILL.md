# SEO and publishing

Common policy: `../../agent/INSTRUCTIONS.md`. This skill does not approve media,
install a platform agent or provide an upload connector.

1. Confirm destination/channel/account, language and target audience. Use source-
   supported claims from the approved script; titles and descriptions must not
   introduce unverified product capabilities, fabricated metrics or keyword spam.
2. Prepare title, description, tags, CTA/pinned comment and source references.
   Apply the selected brand/format rules. Text-only copy drafting is not upload;
   producing thumbnail/caption media still obeys the production gate.
3. Check captions against real audio or an explicitly approved no-voice plan.
   Review thumbnail/cover readability, spelling and rights. Never label synthetic
   mockups as actual product screens.
4. Inventory the final MP4, captions, thumbnail/cover, metadata, approval evidence,
   manifests and SHA-256 values. Confirm the final60 delivery acceptance refers
   to these exact bytes; a preview30 approval is insufficient for a new hash.
5. Package only through a current guarded path. Confirm publication authorization
   separately. If the required external storage/upload connector is unavailable,
   stop and request administrator setup; label local artifacts honestly.
6. After real external success, record remote ID/URL, storage version, artifact
   hashes and destination. Only then record `published`. Report actual results
   and remaining blockers in the handoff, not a simulated success.
