| Product ID | Collection |

Use available authorized knowledge tools; a routing label in brand.json does not
grant access. Read relevant Product Overview/Source Registry documents and current
official topic pages. Status dates describe historical checks, not this run's
reading. If Collections are unavailable, authorized supplied/current official
sources can provide evidence; essential gaps block dependent claims.

Before scripting, save episode RESEARCH.md using the research template. Record the
actual Collection document/revision/date, URL/section, checked date, supported
claim, conditions, permissions, scope, limitations, conflicts and omissions. No
fixed source quota applies. An index or brandkit is not detailed feature evidence.
Resolve material conflicts with the human and omit unsupported optional claims.
Demo values are not customer results; real UI requires authorized dated capture.

Use selected product's optional Content Machine URL from brand.json only when
relevant. Read minimal material, record observed L-code/permalink/read depth and
fact checks; no edits, private bulk copying or transferred browser sessions.
Optional board failure is not a blocker with adequate other evidence. Post
approval is not script approval; scheduling is not publication.

LakeSentry has broader documented coverage. Antares/Alchemist registries have
important documentation gaps; SecondStack's recorded index reading does not prove
feature behavior. Obtain sources for the chosen topic rather than fabricate parity.
