# SecondStack upload checklist

Candidate artifacts, not installed or published:

1. `agent-instructions.txt`: paste into Video Producer's instruction field. No
   separate common instruction file is present in the skill.
2. `video-production-toolkit.zip`: root SKILL.md plus references/runtime assets.
   Submit through Skills > Add Agentic Skill > Install with agent for review.
   Archive layout, binary preservation and size limits still need installer tests.
   Then copy the reviewed skill to Video Producer under Agentic Skills.
3. `product-collections.zip`: unpack locally. Create the four named product
   Collections under Video Producer and upload each product's two Markdown files
   individually; this ZIP is a transport bundle, not a claimed bulk-import format.
   Bind read-only where supported and check Invoke-only visibility. Existing
   documents have dated evidence; this release has not re-read official websites.
4. Enable intended direct-message answer locations and grant intended users Invoke
   through supported settings. Verify/publish the changed Agent version. Do not
   assume a saved draft or a shared file means the Agent has received it.

Run a small installer probe first, then clean-workspace asset/command/approval and
layout tests without external source-library access. Verify runtime prerequisites
and Collections from an Invoke-only account outside the original Project. Until
then this is a locally validated distribution candidate, not universal readiness.

Keep episode state and confidential inputs outside the skill/Collections. Updating
or activating the skill may reinstall files. Preserve exact release archives needed
for continuing episodes; no old-state migration is performed automatically.
